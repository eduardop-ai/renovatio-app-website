# Renovatio App Website

Placeholder marketing/verification site for Renovatio, a personal analytics app for iOS,
hosted at [renovatio.app](https://renovatio.app). Built to support the Apple Developer Program
organization enrollment — Apple requires a public, functional site tied to the domain, not
app screenshots.

Plain HTML/CSS/JS — no build step, no framework, no dependencies. Open `index.html` directly
in a browser to preview, or serve the folder with any static file server.

## Structure

```
index.html      Home page — what Renovatio is, the six modules, facts, contact
privacy.html    Privacy policy (real claims — no server, everything on-device)
terms.html      Terms of use (pre-release note; will apply once the app ships)
css/styles.css  All styling — brand tokens (light + dark) live in :root at the top
js/main.js      Mobile nav toggle + light/dark theme toggle (persisted via localStorage)
assets/screenshots/  Synthetic app screenshots (see below) — currently empty
CNAME           Tells GitHub Pages this site serves renovatio.app
```

## Brand tokens

Colors, type scale, radii and module hues in `css/styles.css` are lifted directly from the
app's own `ui_pass.py` design tokens — do not re-pick them by eye. Both light and dark
palettes are defined in full (not derived from one another). The site follows the reader's
system theme by default; the "Dark mode" / "Light mode" button in the header lets a visitor
override it, stored in `localStorage`.

There is no logo mark or icon by design — only the "Renovatio" wordmark with the violet-to-rose
gradient rule above it. Don't add one.

## Screenshots

Real app screens must never be published — they contain actual personal data (net worth,
resting heart rate, diary entries). Only synthetic screenshots rendered from demo data belong
here. The screenshots section in `index.html` currently shows "pending" placeholders because
the actual PNG files (`launcher-light.png`, `launcher-dark.png`, `carlos-light.png`, etc.,
generated by the app repo's `Website/render_shots.py`) haven't been added to
`assets/screenshots/` yet. Drop them in and wire up `<img>` tags in the screenshots section of
`index.html` to replace the placeholders.

## Content

Copy is drawn from the Renovatio product brief and should stay in that voice: plain
declaratives, specific numbers or none at all, no marketing hype, no exclamation marks, never
explain what "C.A.R.L.O.S." stands for. Don't claim App Store availability until it's actually
live there.

## Hosting: GitHub Pages + Namecheap DNS

Deployed with GitHub Pages, serving straight from the `main` branch (`CNAME` points it at
`renovatio.app`). GitHub Pages must be enabled in the repo's Settings, and Namecheap's Advanced
DNS for `renovatio.app` needs the four GitHub Pages A records plus a `www` CNAME — see the
project setup notes for the exact values. Until DNS + Pages are both live, the domain will keep
showing Namecheap's parking page, which is what triggered the Apple enrollment rejection.
